Put your background track here and name it: wedding.mp3

  assets/music/wedding.mp3

The path is read from weddingData.music in script.js — change it there if you
prefer a different filename or format (.mp3, .m4a and .ogg all work).

Keep the file small (ideally under 3 MB / around 2-3 minutes, looped
automatically) so the invitation stays fast on mobile data. Use music you have
the right to use — a licensed track, a royalty-free instrumental, or something
you own.

The site never autoplays: the track only starts after the visitor taps
"ENTER WEDDING", and the floating ♪ button toggles it at any time.
